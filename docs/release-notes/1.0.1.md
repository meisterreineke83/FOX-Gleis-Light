## Gleis 1.0.1

- Fix: some stations (e.g. *Rheinfelden (Baden)*) led to "Fehler 404 … Could not find timetable
  location". Gleis now uses the correct station id and, if the timetable still doesn't know it,
  falls back to the station's coordinates. Already saved stations are repaired automatically.
- Clearer error messages instead of technical details.

**Deutsch:** Behoben: Bei manchen Bahnhöfen (z. B. Rheinfelden (Baden)) kam „Fehler 404“. Gleis
nutzt jetzt die richtige Kennung und sucht notfalls über die Koordinaten des Bahnhofs. Bereits
gespeicherte Bahnhöfe werden automatisch korrigiert.

Install: Bright Market (`github.com/meisterreineke83/FOX-Gleis-Light`) or `FOX-Gleis-Light.apk` below.
